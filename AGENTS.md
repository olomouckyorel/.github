# Práce se společnými pravidly

- Pro práci v tomto repozitáři načti společný blok v [AGENTS.template.md](AGENTS.template.md) a [CONTRIBUTING.md](CONTRIBUTING.md). Projektová pole šablony jsou vzor, ne instrukce k jinému projektu.
- Správce pro merge je vlastník repozitáře. Agent PR nikdy nemerguje.
- Repo je veřejné: patří sem jen obecná pravidla a šablony, nikoli interní registr projektů, konfigurace přístupů nebo neveřejná evidence.
- Zdroj agentních pravidel je společný blok šablony. Při změně jeho obsahu zvyš verzi; návazné pokyny v CONTRIBUTING.md, README.md a PR šabloně uprav jen tam, kde se změna týká jejich obsahu. Nevytvářej druhou úplnou kopii jádra.
- Před předáním zkontroluj diff, relativní odkazy a git diff --check. Tento dokumentační repozitář nemá testovací aplikaci.
- Aktuální použití šablony a aktualizace kopií popisuje [README.md](README.md).
